Editor de publicaciones

Cargá las fotografías de un episodio, encuadralas, aplicá el estilo de Puntano al Aire y descargá cada pieza por separado. Todo se hace en tu navegador: las imágenes no se suben a ningún servidor.

  1. Crear publicación
  2. Subir una fotografía por celda
  3. Editar
  4. Elegir formato y encuadre
  5. Descargar esa fotografía

Una publicación tiene tres fotografías. Cada una se edita y se descarga de forma independiente: no hace falta exportar las tres.
